# Testing Patterns

**Analysis Date:** 2026-02-15

## Test Framework

**Runner:**
- Node.js built-in execution for verification scripts
- No formal test framework (Jest, Vitest, etc.) configured
- Build-time verification via custom scripts

**Assertion Library:**
- None; custom assertion pattern using `pass()`/`fail()` functions with result tracking

**Run Commands:**
```bash
npm run test:build              # Verify build output integrity (schema, pages, assets)
npm run test:silos             # Check silo integrity (no cross-silo links, schema matching)
npm run test:all               # Run both build and silo tests
npm run lint                   # Run Next.js ESLint checks
```

## Test File Organization

**Location:**
- Test files: `scripts/verify-*.js` in same repo as application (not co-located)
- Pattern: One verification script per concern (build, silos, etc.)

**Naming:**
- `verify-build.js` - Build output validation
- `verify-silos.js` - SEO silo architecture validation

**Structure:**
```
scripts/
├── verify-build.js           # Build integrity tests
├── verify-silos.js           # Silo structure tests
└── [other automation scripts]
```

## Test Structure

**Suite Organization:**
Scripts use function-based organization with logical grouping:

```javascript
// Initialization
const OUT_DIR = path.join(__dirname, '..', 'out');
const results = { passed: [], failed: [] };

// Test helpers
function pass(test) { ... }
function fail(test, reason) { ... }

// Individual test functions
function checkBuildExists() { ... }
function countPages() { ... }
function checkRequiredPages() { ... }
function checkSchemaMarkup() { ... }

// Main execution with organized output
function main() {
  console.log('🔍 Verifying Build Output...\n');

  // Run tests in logical sections
  console.log('--- Required Pages ---');
  checkRequiredPages();

  console.log('\n--- Schema Markup ---');
  checkSchemaMarkup();

  // Summary and exit
}
```

**Patterns:**
- Setup: Initialize results object before running tests
- Teardown: Summary report with exit code at end
- Assertion: Custom `pass()`/`fail()` functions track outcomes

**Patterns:**

**What to Mock:**

## Fixtures and Factories

**Test Data:**
No fixtures or factories used. Tests operate on actual build artifacts:

**Location:**
- Build output: `out/` directory (generated by `npm run build`)
- Test input: List of pages to check hardcoded in each test function

**Example from `verify-build.js`:**
```javascript
function checkRequiredPages() {
  const requiredPages = [
    'index.html',
    'commercial/index.html',
    'residential/index.html',
    'contact/index.html',
    'about/index.html',
    'locations/index.html',
  ];

  for (const page of requiredPages) {
    const pagePath = path.join(OUT_DIR, page);
    if (fs.existsSync(pagePath)) {
      pass(`Required page exists: ${page}`);
    } else {
      fail(`Required page exists: ${page}`, 'Page not found');
    }
  }
}
```

## Test Types

**Build Verification Tests:**
- **File:** `scripts/verify-build.js`
- **Scope:** Validates Next.js build output
- **Checks:**
  - Build directory exists
  - Total page count
  - Required pages present (home, contact, about, etc.)
  - Schema.org JSON-LD markup present on pages
  - Breadcrumb navigation present
  - H1 tags (exactly one per page)
  - Sitemap.xml exists
  - robots.txt exists

**Silo Integrity Tests:**
- **File:** `scripts/verify-silos.js`
- **Scope:** Validates SEO silo architecture (no cross-silo linking)
- **Checks:**
  - Commercial pages only link to commercial pages (or neutral)
  - Residential pages only link to residential pages (or neutral)
  - Schema types match assigned silos
  - No "link bleed" (cross-silo links that dilute authority)
  - Navigational links excluded from silo checks (header, nav, footer)

**Pattern Detection:**
- Commercial patterns: `/commercial-construction/`, `/multi-family/`, `/disaster-recovery/`, etc.
- Residential patterns: `/luxury-custom-homes/`, `/balcony-reconstruction/`, `/exterior-waterproofing/`, etc.
- Neutral patterns: `/`, `/about/`, `/contact/`, `/locations/`, `/services/`

## Common Patterns

**Async Testing:**
Not used; verification scripts are synchronous Node.js operations.

**Error Testing:**
Custom error handling with results tracking:

```javascript
if (fs.existsSync(pagePath)) {
  pass(`Required page exists: ${page}`);
} else {
  fail(`Required page exists: ${page}`, 'Page not found');
}
```

**File System Testing:**
Read HTML files from build output and validate content:

```javascript
function checkSchemaMarkup() {
  const content = fs.readFileSync(pagePath, 'utf-8');
  if (content.includes('application/ld+json')) {
    pass(`Schema markup present: ${page}`);
  } else {
    fail(`Schema markup present: ${page}`, 'No JSON-LD script found');
  }
}
```

**Pattern Matching:**
Regex patterns for link extraction and content validation:

```javascript
// Extract internal links from HTML
const hrefPattern = /href=["']([^"']+)["']/gi;
let match;
while ((match = hrefPattern.exec(mainContent)) !== null) {
  const href = match[1];
  if (href.startsWith('/') && !href.startsWith('//')) {
    links.push(href);
  }
}
```

**Tree Walking:**
Recursive directory traversal for finding pages:

```javascript
function walk(dir) {
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  for (const entry of entries) {
    const fullPath = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      walk(fullPath);
    } else if (entry.name === 'index.html') {
      count++;
    }
  }
}
```

## Before Build Verification

**Automatic Checks:**
Run before deploying:
1. `npm run test:build` - Ensures build output is valid
2. `npm run test:silos` - Ensures SEO silo integrity

**Integration:**
- Can be run locally: `npm run test:all`
- Recommended: Run on developer machine before git push
- Not automated on Netlify (manual `netlify deploy` skips build stage)

## Special Considerations

**Build Artifacts:**
- Tests require `out/` directory from `npm run build`
- If `out/` doesn't exist, tests report failure with helpful message:
  ```javascript
  if (!fs.existsSync(OUT_DIR)) {
    fail('Build output directory exists', 'out/ directory not found. Run npm run build first.');
    return false;
  }
  ```

**Static Export:**
- Tests validate static HTML export (Next.js `output: "export"`)
- No server rendering; all pages are pre-generated `.html` files

**Silo Architecture:**
- Tests enforce "Double Helix" SEO strategy
- Commercial and residential silos must remain separate (except on neutral hub pages)
- Violations prevent deploy (exit code 1)
