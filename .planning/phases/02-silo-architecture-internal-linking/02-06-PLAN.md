<task type="auto">
  <name>Task 1: Create pre-deploy validation script</name>
  <files>scripts/validate-pre-deploy.js</files>
  <action>
    Create `scripts/validate-pre-deploy.js` that performs these checks:

    **Check 1: Meta titles present.**
    Scan every `page.tsx` in `app/`. Each must export or define a `metadata` object with a `title` property. Report any pages missing titles.

    **Check 2: Canonical URLs correct.**
    For every page.tsx that has a canonical URL in `metadata.alternates.canonical`:
    - The canonical must be self-referencing (matches the page's own URL derived from its file path)
    - The canonical must use the full domain: `https://floridaconstructionspecialists.com/...`
    - No canonical should point to a URL that is a redirect target in netlify.toml

    **Check 3: No broken internal links.**
    For every `href` value in every page.tsx that starts with `/`:
    - The target URL must either (a) exist as a page in `app/` or (b) be a redirect in `netlify.toml` or (c) be an anchor/hash link
    - Report any links to URLs that don't exist and aren't redirected

    **Check 4: No redirect chains.**
    Read all redirects from `netlify.toml`. For each redirect's `to` value, check if that URL is itself a `from` in another redirect. If so, it's a chain. Report all chains.

    **Check 5: Sitemap-to-output consistency.**
    After `npm run build` has been run (so `out/` exists):
    - Read `public/sitemap.xml`
    - For each URL in the sitemap, verify the corresponding HTML file exists in `out/`
    - For each HTML file in `out/`, verify it appears in the sitemap (unless it's a redirected or noindexed page)
    - Report mismatches in both directions

    **Check 6: No pages in sitemap that are redirected.**
    Cross-reference sitemap URLs against netlify.toml redirects. No redirected URL should appear in the sitemap.

    **Output format:**
    ```
    === PRE-DEPLOY VALIDATION ===

    ✓ Meta titles: 428/428 pages have titles
    ✓ Canonical URLs: 428/428 correct
    ✗ Broken internal links: 3 found
      - app/foo/page.tsx links to /bar/ (not found)
      - ...
    ✓ Redirect chains: 0 found
    ✓ Sitemap consistency: 361 URLs match output

    RESULT: 1 FAILURE (broken internal links)
    ```

    Exit code 0 if all checks pass, exit code 1 if any failures.
  </action>
  <verify>
    Run: `node scripts/validate-pre-deploy.js`
    - Script runs all 6 checks without crashing
    - If any failures are found, note them (they'll be fixed in the next step of this task)
  </verify>
