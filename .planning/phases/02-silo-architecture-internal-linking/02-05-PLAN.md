<objective>
Build a link graph of the entire site, identify orphan pages (fewer than 3 inbound internal links), verify top pages are within 2 clicks of homepage, and fix any issues found.

Purpose: Orphan pages waste crawl budget and never rank. Pages buried too deep (3+ clicks from homepage) get less link equity. This plan ensures every page is well-connected and important pages are prominently linked.

Output: Link graph report with orphan list and crawl depth analysis, all orphans fixed, top pages verified within 2 clicks.
</objective>

<task type="auto">
  <name>Task 1: Build link graph, identify orphans and crawl depth issues</name>
  <files>
    scripts/audit-link-graph.js
    seo/link-graph-report.json
  </files>
  <action>
    Create `scripts/audit-link-graph.js` that:

    1. **Scans all page.tsx files** under `app/` recursively. For each page:
       - Determine its URL from its file path (e.g., `app/commercial/guides/foo/page.tsx` → `/commercial/guides/foo/`)
       - Extract ALL href values from the file content (regex: `href=["'](\/[^"'#]+)["']` and `href: ["'](\/[^"'#]+)["']`)
       - Record each (source URL, target URL) pair

    2. **Build inbound link map:** For each URL in the site, count how many other pages link TO it.
       ```json
       { "/commercial/": 45, "/commercial/guides/foo/": 3, ... }
       ```

    3. **Identify orphans:** Pages with fewer than 3 inbound internal links. Exclude:
       - Homepage (it's the root, linked by nav on every page)
       - Pages that are redirected (not real pages anymore)
       - Noindexed pages (premium-homepage, etc.)

    4. **Calculate crawl depth via BFS from homepage:**
       - Start at `/` (homepage)
       - Level 0: homepage
       - Level 1: all pages directly linked from homepage
       - Level 2: all pages linked from Level 1 pages (not yet visited)
       - Level 3+: continue until all reachable pages found
       - Track depth for every page

    5. **Identify the top 20-30 most important pages** (hub pages, main service pages, service+location pages for primary cities like Tampa, Clearwater, St Petersburg) and verify they are at depth <= 2.

    6. **Output `seo/link-graph-report.json`:**
       ```json
       {
         "generated": "...",
         "totalPages": N,
         "totalInternalLinks": N,
         "orphans": [
           { "url": "/some-page/", "inboundLinks": 1, "linkedFrom": ["/other-page/"] }
         ],
         "crawlDepth": {
           "depth0": ["/"],
           "depth1": ["/commercial/", "/residential/", ...],
           "depth2": ["/commercial/guides/...", ...],
           "depth3plus": [...]
         },
         "topPagesDepth": [
           { "url": "/commercial/", "depth": 1, "inboundLinks": 45 },
           ...
         ],
         "stats": {
           "avgInboundLinks": N,
           "medianInboundLinks": N,
           "maxDepth": N,
           "pagesAtDepth3Plus": N
         }
       }
       ```

    7. **Print summary** to console: orphan count, max depth, any top pages deeper than 2 clicks.
  </action>
  <verify>
    Run: `node scripts/audit-link-graph.js`
    - Script completes without errors
    - `seo/link-graph-report.json` exists
    - Console shows orphan count and crawl depth stats
  </verify>
  <done>Link graph report generated with orphan identification and crawl depth analysis for every page on the site.</done>
</task>

<task type="auto">
  <name>Task 2: Fix orphan pages and crawl depth issues</name>
  <files>app/**/page.tsx</files>
  <action>
    Based on the link graph report from Task 1:

    **Fix orphan pages (fewer than 3 inbound links):**
    For each orphan page, add links to it from 2-3 related pages. Strategy:
    - If an orphan is an article in a silo, add it to the `internalLinks` array of 2-3 sibling articles in the same silo
    - If an orphan is a service+location page, add it to the `NearbyLocations` or `RelatedServices` of nearby pages
    - If an orphan is a service page, add it to the parent hub page's links
    - The guides index pages (from Plan 03) should help -- they link to every article in their silo

    **Fix crawl depth issues (important pages at depth 3+):**
    - If a top-20 page is at depth 3+, add a direct link to it from a depth-1 page (typically a hub page or the homepage)
    - The homepage should link to all three hub pages (verify this)
    - Hub pages should link to their most important service+location pages (verify this)

    **Approach for bulk fixes:**
    If there are many orphans (>20), write a small script that reads the report and adds links programmatically. If few (<20), fix manually.

    **Important:** When adding links to fix orphans, maintain silo discipline. Don't add cross-silo links to fix orphan counts.

    After fixes, re-run `node scripts/audit-link-graph.js` to verify all orphans are resolved and top pages are within 2 clicks.
  </action>

    - Updated `seo/link-graph-report.json` confirms fixes
  </verify>
