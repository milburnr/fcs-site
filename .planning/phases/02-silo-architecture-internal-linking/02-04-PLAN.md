<task type="auto">
  <name>Task 1: Bulk-update all internal link references to new silo URLs</name>
  <files>
    scripts/update-internal-links.js
    app/**/page.tsx
    seo/link-update-report.json
  </files>
  <action>
    Create `scripts/update-internal-links.js` that:

    1. **Reads `seo/article-classification.json`** to build a map of old URLs to new URLs:
       ```
       /{slug}/ → /{silo}/guides/{slug}/
       ```
       Also include the hub consolidation redirects from Plan 01:
       ```
       /commercial-construction/ → /commercial/
       /services/commercial/ → /commercial/
       /custom-homes/ → /residential/
       /services/residential/ → /residential/
       /insurance-restoration/ → /insurance/
       /disaster-recovery-insurance-restoration/ → /insurance/
       /services/disaster-recovery/ → /insurance/
       ```

    2. **Scans ALL page.tsx files** in the entire `app/` directory tree (recursive).

    3. **For each file,** finds all href values (both in JSX `href="..."` and in data arrays like `internalLinks`, `relatedLinks`, etc.) that match any old URL in the map, and replaces them with the new URL.

    4. **Also updates any string literals** that contain old URLs (e.g., canonical references in other pages' link arrays, image alt text references, etc.).

    5. **Tracks all changes** and writes `seo/link-update-report.json`:
       ```json
       {
         "generated": "2026-02-...",
         "totalFilesScanned": N,
         "totalFilesUpdated": N,
         "totalReplacementsCount": N,
         "updates": [
           { "file": "app/commercial/guides/foo/page.tsx", "replacements": 3, "oldUrls": ["/bar/", "/baz/", "/commercial-construction/"] }
         ]
       }
       ```

    6. **Prints summary** to console.

    Run the script after creation.

    **Important:** The script must handle:
    - Both quoted patterns: `href="/slug/"` and `href='/slug/'`
    - Array entries: `{ href: "/slug/", label: "..." }`
    - Link component usage: `<Link href="/slug/">`
    - Template literals: `` href={`/slug/`} ``
    - The full domain form: `https://floridaconstructionspecialists.com/slug/`
  </action>
  <verify>
    Run: `node scripts/update-internal-links.js`
    - Script completes without errors
    - `seo/link-update-report.json` exists
    - Verify zero old article URLs remain: for each moved article, `grep -r "\"/${slug}/\"" app/ --include="*.tsx"` returns zero matches (spot-check 10 random articles)
    - Verify zero old hub URLs remain: `grep -r '"/commercial-construction/"' app/ --include="*.tsx"` returns zero
  </verify>
  <done>Every internal link across all page.tsx files now points to the correct new silo URL or hub URL. Zero references to old pre-move URLs. Link update report generated.</done>
