  <action>
    Create `scripts/move-articles-to-silos.js` that reads `seo/article-classification.json` and for EACH article:

    **1. Create target directory:**
    ```
    app/{silo}/guides/{slug}/
    ```

    **2. Move the page file:**
    Copy `app/{slug}/page.tsx` to `app/{silo}/guides/{slug}/page.tsx`, then delete the old directory.

    **3. Update canonical URL in the page file:**
    Find the canonical URL pattern (either in `alternates.canonical` or in `metadata` object) and replace:
    - Old: `https://floridaconstructionspecialists.com/{slug}/`
    - New: `https://floridaconstructionspecialists.com/{silo}/guides/{slug}/`
    Also update any `openGraph.url` if present.

    **4. Update breadcrumbs in the page file:**
    Find the `breadcrumbItems` array (or similar) and replace it with a 4-level breadcrumb:
    ```typescript
    const breadcrumbItems = [
      { name: "Home", href: "/" },
      { name: "{SiloLabel}", href: "/{silo}/" },
      { name: "Guides", href: "/{silo}/guides/" },
      { name: "{PageTitle}", href: "/{silo}/guides/{slug}/" },
    ];
    ```
    Where SiloLabel is "Commercial" for commercial, "Residential" for residential, "Insurance" for insurance. Extract PageTitle from the existing breadcrumb's last item name.

    **5. Generate redirect block** and collect it. After processing all articles, append all redirect blocks to netlify.toml BEFORE the catch-all `/*` redirect at the bottom.

    **Script behavior:**
    - Process articles in batches (log progress every 50 articles)
    - If a target directory already exists, skip that article (idempotent)
    - If the source page.tsx doesn't exist, log a warning and skip
    - At the end, print summary: moved count, skipped count, redirect count
    - Handle the case where breadcrumb format varies across pages (some use `breadcrumbItems`, some may use inline arrays in the Breadcrumb component). Search for common patterns: `breadcrumbItems`, `items={[`, `Breadcrumb items=`

    **After the script runs:**
    - Verify no old article directories remain at root
    - Verify the three guides directories contain the expected number of articles

    **Also handle existing Phase 1 redirect chains:** Some Phase 1 redirects point TO old article URLs that are now being moved. After generating the new redirects, scan netlify.toml for any existing redirect whose `to` value matches a moved article's old URL, and update it to point directly to the new silo URL.
  </action>
