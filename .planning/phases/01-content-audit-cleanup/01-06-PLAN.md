<task type="auto">
  <name>Task 1: Create sitemap generation script</name>
  <files>scripts/generate-sitemap.js</files>
  <action>
Create `scripts/generate-sitemap.js` that:

1. **Discovers pages:** Recursively scans `app/` for `page.tsx` files, extracting the URL path from the directory structure (e.g., `app/commercial-construction-tampa/page.tsx` -> `/commercial-construction-tampa/`)

2. **Excludes non-indexable pages:**
   a. Pages with `robots: { index: false }` in their metadata export (noindexed pages)
   b. Pages whose URL has a redirect `from` entry in `netlify.toml` (redirected pages)
   c. The `app/layout.tsx` file (not a page)
   d. Any `app/api/` routes if they exist
   e. Any `app/keystatic/` routes if they exist

3. **Generates XML:** Creates valid XML sitemap at `public/sitemap.xml`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://floridaconstructionspecialists.com/</loc>
    <lastmod>2026-02-15</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://floridaconstructionspecialists.com/commercial-construction-tampa/</loc>
    <lastmod>2026-02-15</lastmod>
    <changefreq>monthly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
```

4. **Priority rules:**
   - Homepage: 1.0
   - Hub pages (/services/, /locations/, /insurance-restoration/): 0.9
   - Service-location pages: 0.8
   - Location hub pages (/locations/tampa-fl/): 0.7
   - Article/blog pages: 0.6
   - Utility pages (contact, about): 0.5

5. **lastmod:** Use today's date for all pages (we just modified descriptions across the site)

6. **Trailing slashes:** All URLs must end with `/` (matching Next.js `trailingSlash: true` config)

7. **Base URL:** `https://floridaconstructionspecialists.com`

8. **Output:** Print summary -- total URLs included, URLs excluded (with reasons), any warnings

Run the script:
```bash
node scripts/generate-sitemap.js
```
