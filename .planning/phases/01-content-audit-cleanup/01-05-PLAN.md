  <action>
Read `audit-meta.json` to identify all pages with descriptions over 160 characters. Cross-reference with `seo/thin-content-decisions.json` to exclude pages that were redirected or noindexed (they don't need description fixes).

For each page needing a rewrite, generate a new description following these rules:

**Template by page type:**

**Service-location pages** (e.g., /commercial-construction-tampa/):
Format: `{Service} in {City}: {key differentiator or scope}. {trust signal}. {CTA}.`
Example: `Commercial construction in Tampa: $500K-$25M projects, design-build, 40+ years experience. Licensed CGC. Request a project bid today.`
Target: 155-160 chars

**Article/blog pages** (e.g., /boost-sales-with-effective-.../):
Format: `{Topic summary in 1 sentence}. {Value prop}. {CTA}.`
Example: `How effective commercial signage drives restaurant revenue in Tampa Bay. Expert strategies from 40+ years of builds. Read more.`
Target: 150-158 chars

**Hub pages** (e.g., /services/, /locations/):
Format: `{What this hub covers}. {Coverage scope}. {CTA}.`
Example: `Full-service commercial and residential construction across Tampa Bay. Licensed CGC, 40+ years. Explore our services.`
Target: 150-158 chars

**Location pages** (e.g., /locations/tampa-fl/):
Format: `{Service} contractor serving {City, FL}. {Differentiator}. {CTA}.`
Example: `Licensed construction contractor serving Tampa, FL. Commercial, residential, and insurance restoration. Get a free estimate.`
Target: 150-158 chars

**CTA options** (vary to avoid repetition):
- "Request a free estimate today."
- "Call (813) 906-1302 for a quote."
- "Schedule your consultation now."
- "Get a free project assessment."
- "Contact our team today."
- "Read more."
- "Learn how."

**IMPORTANT:**
- Use the page's PRIMARY KEYWORD from `seo/keyword-map.json` naturally in the description
- Each description must be complete (no truncation mid-sentence)
- Descriptions for the same service in different cities must differ (not just city name swap)
- Keep the original description's core message/value prop where possible -- just tighten it

Write to `seo/description-rewrites.json`:

Full-service design-build contractor with 40+ years experience in Hillsborough County. We handle everything from pre-construction planning to final inspections. Request your project bid today.",

<task type="auto">
  <name>Task 2: Apply description rewrites to page.tsx source files</name>
  <files>
scripts/rewrite-descriptions.js
  </files>
  <action>
Create `scripts/rewrite-descriptions.js` that:

1. Reads `seo/description-rewrites.json`
2. For each rewrite entry:
   a. Opens the page.tsx file at the specified path
   b. Finds the `description:` property in the metadata export
   c. Replaces the old description string with the new one
   d. Preserves all other metadata and file content
3. Handles both single-line and multi-line description strings
4. Does NOT break TypeScript syntax (watch for quote escaping, trailing commas)
5. Logs: files updated, files skipped (description already correct or file not found), errors

Safety checks:
- Before writing, verify the old_description matches what's in the file (guard against stale data)
- If old_description doesn't match, SKIP and log a warning (page was already modified)
- Support `--dry-run` flag to preview changes without writing

Run:
```bash
node scripts/rewrite-descriptions.js --dry-run

node scripts/rewrite-descriptions.js
```
