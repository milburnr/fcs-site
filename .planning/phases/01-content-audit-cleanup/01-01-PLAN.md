<task type="auto">
  <name>Task 2: Remove keywords meta tag from all pages (AUDIT-06)</name>
  <files>
scripts/remove-keywords-meta.js
app/layout.tsx
  </files>
  <action>
Create a Node.js script `scripts/remove-keywords-meta.js` that:

1. Recursively finds all `page.tsx` files under `app/`
2. Also processes `app/layout.tsx`
3. For each file, detects and removes the `keywords` property from the metadata export
4. Handles these formats:
   - Single-line: `keywords: ["a", "b", "c"],`
   - Multi-line array:
     ```
     keywords: [
       "keyword1",
       "keyword2",
     ],
     ```
   - With or without trailing comma after the closing bracket
5. Removes the entire `keywords` property including its value (the array) and trailing comma
6. Does NOT break the surrounding TypeScript object syntax
7. Writes the modified file back, preserving all other content
8. Logs: total files scanned, files modified, files skipped (no keywords found)

After creating the script, RUN IT:
```bash
node scripts/remove-keywords-meta.js
```

Then verify layout.tsx specifically -- research found keywords at lines 35-42 in layout.tsx. Confirm they are gone.

IMPORTANT: The script must handle edge cases:
- `keywords` as the last property (no trailing comma needed)
- `keywords` as a middle property (remove line + trailing comma cleanly)
- Multi-line arrays spanning 5-20 lines
- Do NOT remove the word "keywords" if it appears in string content (descriptions, titles)

Expected: ~174 page.tsx files + 1 layout.tsx = ~175 files modified.
  </action>
  <verify>
Run these checks:
1. `grep -r "keywords:" app/ --include="*.tsx" -l | wc -l` should return 0
2. `grep "keywords" app/layout.tsx` should return nothing (or only string content references)
3. `npx tsc --noEmit` (or `npm run build`) on a sample of 5 modified files to confirm no TypeScript syntax errors
4. Spot-check 3 files: one that had single-line keywords, one with multi-line, one that's layout.tsx
  </verify>
  <done>Zero page.tsx files have a `keywords` property in their metadata export. layout.tsx keywords are removed. No TypeScript syntax errors introduced.</done>
</task>
