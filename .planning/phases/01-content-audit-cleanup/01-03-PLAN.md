<task type="auto">
  <name>Task 3: Execute redirect and noindex decisions</name>
  <files>
netlify.toml
  </files>
  <action>
Read `seo/thin-content-decisions.json` and execute each decision:

**For "redirect" decisions:**
1. Add 301 redirect to `netlify.toml` (before the catch-all `/*` redirect):
```toml
[[redirects]]
  from = "/page-being-redirected/"
  to = "/target-page/"
  status = 301
```
2. Delete the source page directory: `rm -rf app/{slug}/`
3. Check for internal links pointing to the redirected page and update them to point to the target

**For "noindex" decisions:**
1. Open the page.tsx file
2. Add `robots: { index: false, follow: true }` to the metadata export
3. Keep the page file (it still serves a purpose, just shouldn't be indexed)

**For "expand_later" decisions:**
1. Do nothing -- these are tracked for Phase 4
2. Optionally add a comment in the page.tsx: `// TODO Phase 4: Expand to 800+ words`

After all changes:
- Count remaining indexable pages
- Log all changes made
  </action>
  <verify>
1. For each "redirect" page: `ls app/{slug}` should fail, `grep "{slug}" netlify.toml` should show redirect
2. For each "noindex" page: `grep "index: false" app/{slug}/page.tsx` should match
3. `grep -r "noindex" app/ --include="*.tsx" | wc -l` shows expected count of noindexed pages
4. No broken internal links: spot-check 3 redirected pages for internal link updates
  </verify>
  <done>All "redirect" pages have 301s in netlify.toml and source files deleted. All "noindex" pages have robots.noindex in metadata. No thin pages remain without a decision.</done>
