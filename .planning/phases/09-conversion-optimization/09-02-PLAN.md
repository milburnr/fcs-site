   c. Extracts the existing h2 text content to check if it's generic ("Ready to Get Started?", "Get Your Free Estimate", etc.) or topic-specific

   e. Adds `import { GuideCTA } from "@/components/GuideCTA";` to the imports section if not already present
   f. Removes the `import { BUSINESS_INFO } from "@/lib/constants";` line ONLY IF BUSINESS_INFO is no longer referenced elsewhere in the file after the CTA section removal

- "Contact Us Today"

- Any heading that is just "Ready to" + generic phrase
