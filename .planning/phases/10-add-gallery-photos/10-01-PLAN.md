<task type="auto">
  <name>Task 1: Create image processing script and R2 upload script</name>
  <files>scripts/process-gallery-photos.js, scripts/upload-gallery-to-r2.sh</files>
  <action>
Create `scripts/process-gallery-photos.js` using Sharp (already installed in `tools/image-processing/node_modules`). The script:

1. Reads 8 project folders from `/Volumes/External-2TB/Projects/fcs-photos`
2. Maps folder names to slugs:
   - "5th Ave home" -> "5th-ave-home"
   - "Bayshore Drive" -> "bayshore-drive"
   - "Commodore's Cove" -> "commodores-cove"
   - "Horeseshoe Loop Rd" -> "horseshoe-loop-rd" (fix typo in slug)
   - "Italian Club" -> "italian-club"
   - "MVP Orthodontics" -> "mvp-orthodontics"
   - "Race Track" -> "race-track"
   - "World Vision" -> "world-vision"
3. For each folder, reads all `.jpg`, `.jpeg`, `.png` files (case-insensitive match for `.JPG` too)
4. Sorts files alphabetically (DJI_ before JGP_ -- drone overview shots sort first)
5. For each image, produces two WebP outputs:
   - `fcs-{slug}-{NN}-full.webp` at 1600px wide, quality 82
   - `fcs-{slug}-{NN}-thumb.webp` at 400px wide, quality 82
   - NN is zero-padded two digits (01, 02, ... 49)
   - `withoutEnlargement: true` to avoid upscaling small images
6. Output directory: `/Volumes/External-2TB/Projects/fcs-gallery-processed/{slug}/`
7. Prints progress per project and a final summary with photo counts per project
8. At the end, writes a JSON manifest to `/Volumes/External-2TB/Projects/fcs-gallery-processed/manifest.json` containing `{ projects: [{ slug, name, photoCount }] }` -- this will be used to create gallery-data.ts

Use `require('sharp')` with explicit path to `../../tools/image-processing/node_modules/sharp` since Sharp is installed there, not in the site's node_modules.

Create `scripts/upload-gallery-to-r2.sh`:
1. Creates R2 bucket `fcs-gallery` if it doesn't exist: `wrangler r2 bucket create fcs-gallery --remote 2>/dev/null || true`
2. Iterates over processed project directories in `/Volumes/External-2TB/Projects/fcs-gallery-processed/`
3. Uses `xargs -P 8` for parallel upload (8 concurrent uploads)
4. Upload path pattern: `gallery/{slug}/fcs-{slug}-NN-{size}.webp`
5. Content-Type header: `image/webp`
6. Prints progress per project
7. Make the script executable (`chmod +x`)
