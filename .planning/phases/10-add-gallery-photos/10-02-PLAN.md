  <action>
Install yet-another-react-lightbox:
```bash
npm install yet-another-react-lightbox
```

Create `components/GalleryCarousel.tsx` as a `'use client'` component:

1. Import YARL core + plugins:
   - `Lightbox` from `yet-another-react-lightbox`
   - `Inline` from `yet-another-react-lightbox/plugins/inline`
   - `Thumbnails` from `yet-another-react-lightbox/plugins/thumbnails`
   - `Fullscreen` from `yet-another-react-lightbox/plugins/fullscreen`
   - `Zoom` from `yet-another-react-lightbox/plugins/zoom`
   - CSS: `yet-another-react-lightbox/styles.css` and `yet-another-react-lightbox/plugins/thumbnails.css`

2. Props interface: `{ slides: { src: string; thumb: string; alt: string }[] }`

3. State: `lightboxOpen` (boolean), `currentIndex` (number)

4. Render TWO Lightbox instances (per research Pattern 2):
   - **Inline carousel:** Uses `Inline` + `Thumbnails` plugins. Style: `width: 100%, maxWidth: 1200px, aspectRatio: 3/2`. On click: opens lightbox at clicked index. `carousel: { finite: true }`. Thumbnails config: use `thumb` URL from slides via the `thumbnail` property on each slide object.
   - **Fullscreen lightbox:** Standard Lightbox with `Thumbnails` + `Fullscreen` + `Zoom` plugins. Opens when `lightboxOpen` is true. Closes on backdrop click or Escape.

5. YARL slide format: `{ src: string, alt: string }` -- for thumbnails, YARL reads from the same src unless you provide a custom render. Since we have separate thumb URLs, pass thumbnails via the `thumbnails` plugin's `vignette` or use YARL's srcSet approach. Simplest: for the inline carousel, images display at container size so full-size URLs are fine. For thumbnail strip, YARL auto-generates thumbnails from `src` by default. To use our custom thumb URLs, set each slide's `thumbnail` property: `{ src: fullUrl, alt, thumbnail: thumbUrl }`.

6. Center the carousel container with `mx-auto`.
  </action>
